## 本次保留和变更

保留原 panel.json、数据库和会话、证书、下载/续传目录、配置备份、游戏目录及全部非托管插件。只替换发布包中的面板代码、静态资源和依赖声明；依赖通过已下载的固定 wheel 离线更新。添加 systemd `RestartPreventExitStatus=78`，支持配置启动恢复。仅重启面板服务，游戏进程和地图保持运行。

原服没有两个新面板辅助插件，因此从已验签载荷中核对文件哈希后，添加并热加载 `panel_hostname.smx`、`panel_join_password.smx`。没有安装整套 Metamod/SourceMod 覆盖既有框架，也没有把既有插件伪造为安装器托管收据。当前服名没有托管文件时 hostname helper 显示 missing，表示还未由基础设置保存名称；现有运行服名保持不变。

轻量采样和日志轮转工作独立保留，部署说明见 [operations](../../tools/operations/README.md)。正在使用的其他插件测试目录保留。

## 备份集合

私有备份保存在维护者电脑的独立受限目录，不进入仓库或 GitHub Release。恢复前核对目录内 `SHA256SUMS`、各归档校验结果和 `BACKUP_VERIFIED.json`。

- `production-control.tar.gz`：切换前面板代码、配置、插件框架、SourceMod 插件/源代码/扩展/gamedata/翻译/data、游戏 cfg/scripts、LinuxGSM 和服务配置。排除下载缓存和 SourceMod 日志，后两者由大文件备份覆盖。
- `production-sqlite.tar.gz`：切换前 5 个 SQLite 数据库的在线一致性快照；不要将运行中普通 tar 里的 SQLite 文件当作一致性快照。
- `production-after.tar.gz`：停止旧面板之后最后一份数据库快照、切换后数据库快照、最新 cfg、辅助插件、服务配置、nginx TLS 公钥及私钥、文件清单。凭据文件保持私有。
- `production-state.tar.gz`：主目录的用户数据补充备份，含全部自定义 VPK、插件和依赖、配置/脚本/数据、下载缓存、日志及既有备份。排除原版游戏二进制、pak、媒体视频及标准战役及 Valve styleguide 地图的 BSP/NAV；自定义 VPK 和其他非标准散装地图保留，完整纳入清单见 scope/inventory 文件。按服务端文件 SHA256 复用本地已有内容，缺失内容先做服务端静态副本再补传，最终生成完整 tar 并逐文件校验。中止的过宽传输文件只提供哈希匹配的完整文件内容，不作为有效归档。在线数据并非在同一时刻冻结；控制备份及一致性数据库快照是恢复基准。
- 日志轮转前完整日志、轻量运维变更前后配置、旧安装测试证据另有独立归档。旧测试证据验证后才删除对应测试目录。

## 恢复边界

恢复前停止要恢复的面板服务，按目标时间选择代码、配置和一致性数据库快照。数据库恢复需同时处理相应 WAL/SHM，并先备份当前数据，避免覆盖上线后新增账号或设置。配置/证书/插件的 uid、gid、mode 可从归档和逐文件索引核对。

仅回退面板代码时，不回退游戏配置或插件目录，不覆盖正在进行的其他工作。只有要恢复游戏文件或游戏数据库时才安排停服；不能直接将整个在线 state 归档覆盖到正在运行的服务器。

已由新手安装器管理的主机可用 `l4d2panel-recover` 恢复待重启配置；本次旧安装不新增这一 root helper。既有安装应以原服务用户执行实际面板入口的 `--config <真实配置> --restore-config`，再由管理员重启面板。该命令只用于对应的待恢复配置，不是整服回滚。
