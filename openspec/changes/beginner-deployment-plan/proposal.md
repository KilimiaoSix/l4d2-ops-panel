## Why

普通玩家仍需要自行构建前端、同步文件、配置 Python/systemd，并手动安装 SourceMod 才能使用面板的主要能力。用户在 Claude 会话 `0e1ac5e8-6eeb-482c-af37-bb9d27c1b6e7` 中要求制定“简单命令部署、主要通过面板运维”的开发计划；原草稿和三份设计存在交叉契约冲突，尚未形成可实施清单。

本次完成规划工件并关闭设计矛盾，保留未来开发任务为未完成状态。以下行为描述的是拟实现目标，不表示当前代码已经提供。

2026-09-27 用户已授权按计划实施；随后明确发布资源使用 GitHub，不使用现有游戏服务器。默认分发改为 GitHub Releases，独立国内镜像保留为可选配置；签名验证、真实公开下载及安装验收仍需完成。

## What Changes

**安装与引导**
- From：开发机编译、rsync、交互式 install.sh。
- To：含 SPA、固定插件载荷的 Release；root 运行零交互 get.sh，创建专用用户，浏览器继续向导。
- Reason：移除新手不能独立完成的构建和系统配置步骤。
- Impact：新增 Ubuntu 22.04/24.04 x86_64 + systemd 的默认路径；现有 LinuxGSM 作为高级路径继续可用，不自动接管旧安装。

**面板配置**
- From：编辑 panel.json 后手工重启。
- To：owner 在网页修改明确允许的配置，校验、备份、原子保存，必要时由 systemd 重启并确认新进程；提供单命令恢复。
- Reason：遵守用户已选定的自动重启方案。
- Impact：增加配置、向导持久状态和重启协调，保留自定义配置路径与旧数据。

**插件与基础游戏设置**
- From：手工下载安装第三方组件，缺少基础服名/进服密码/人数入口。
- To：声明式插件包，最小默认、完整组合可在首次或事后选择；新增中文服名、进服密码、地区和具备依赖条件时的人数设置。
- Reason：让网页操作覆盖从首次开服到邀请朋友的完整路径。
- Impact：需要发布物、插件版本/依赖/许可清单及真实引擎验收；安装文件、插件已加载、游戏可入服分别判定。

## Capabilities

### New Capabilities
- `release-bootstrap`：GitHub 可校验发布物、可选镜像与离线入口、root 引导、专用用户、重复运行和恢复。
- `panel-onboarding`：持久向导、未装游戏的空状态、加入指南与可达性确认。
- `panel-configuration`：配置白名单、真实配置路径、并发保存、重启协调及回滚。
- `plugin-packs`：最小/全套选择、依赖解析、受保护安装、收据和能力确认。
- `basic-server-settings`：中文服名、进服密码、地区、可选多人合作和实际生效验证。

### Modified Capabilities

尚无已入库的 OpenSpec capability；以上均建立新的需求基线，不表示重写已有功能。

## Impact

实施涉及发布工具与 CI、安装脚本、后端配置/任务/插件/游戏服务、少量 store 扩展、前端向导与设置页、SourceMod 插件及测试。拆分为 P0 共用契约、M1 发布与配置、M2 插件包、M3 基础设置、E 端到端验收五组工作，避免单次跨层大改。

不做多服管理、游戏覆盖重装/自动更新、整服备份产品、云厂商安全组 API、面板网页自动升级、ARM 游戏兼容或通用远程命令执行器。配置与插件事务备份属于本次必要恢复机制，不等同于整服备份功能。
